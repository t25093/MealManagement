## טיפול בתחרות על משאב (Concurrency)

**המשאב המוגבל** הוא הכמות שנותרה להכנה מכל מנה בארוחה (`MealDish`).
**התחרות** מתרחשת כשכמה משתתפות לוקחות את אותה מנה בו-זמנית, או כשבעלת הארוחה משנה את מספר האורחים בזמן שמשתתפת לוקחת.
**הטיפול:** Optimistic Concurrency עם עמודת המערכת `xmin` של PostgreSQL כ-concurrency token (מאפיין `uint Version` עם `IsRowVersion()`).
כל עדכון נשמר רק אם השורה לא השתנתה מאז שנקראה. בהתנגשות השרת מחזיר `409 Conflict`, נכתב לוג Warning, והלקוח מציג הודעה ומרענן את הנתונים.

**למה `xmin` ולא Guid מנוהל:** PostgreSQL מעדכן את `xmin` אוטומטית בכל שינוי של שורה, כך שאין קוד לתחזק ואין סיכון לשכוח לעדכן את הערך. החיסרון הוא שהפתרון ייחודי ל-PostgreSQL, וזה מקובל כי הפרויקט בנוי עליו.
